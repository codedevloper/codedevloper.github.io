# Security policy

Found a security issue in this site or in another `codedevloper` repository? Thank you for reporting it.

- Report it privately through GitHub: **Security → Report a vulnerability** on the affected repository
  ([this one](https://github.com/codedevloper/codedevloper.github.io/security/advisories/new)). Please do not open a public issue.
- Include what you found, how to reproduce it and the impact you expect.
- You can expect an acknowledgement within a few days. Please give me reasonable time to fix the issue before you
  disclose it.

This site is static: no forms, cookies, accounts, analytics or third-party scripts. The only thing it stores is your
light/dark choice, in your own browser.
